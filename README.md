# HavanaMaps GitHub Pages

Site estatico pronto para publicar no GitHub Pages.

## Rotas

- `/maps/havana-original-updated/` - Havana Impo Reduced
- `/maps/havana-reduced/` - Havana 70%
- `/maps/havana-updated/` - Havana 70% + Impo Reduced

## Publicacao

Suba todo o conteudo desta pasta como raiz do repositorio.

Como os arquivos `.unityweb` passam de 25 MB, o upload pelo site do GitHub pode falhar. Use GitHub Desktop ou Git na maquina para publicar.

No GitHub Pages, use:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/root`

Todos os arquivos estao abaixo de 100 MB, entao nao precisa Git LFS.
